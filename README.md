# Cosmic Singing Bowls

A scroll-driven visual story of the paper *Impact on Inferred Neutron Star Equation of State due to Nonlinear Hydrodynamics, Background Spin, and Relativity* (Bretz & Yu, CQG). Light theme: clay red and greenish dark blue.

## Layout
- `site/` – the static page. No build step; all paths are relative, so it drops into any GitHub Pages repo.
  - `index.html`, `css/style.css`, `js/main.js` (progress, reveal, animation pause buttons), `js/widget_tides.js`, `js/widget_retune.js` and `js/widget_snr.js` (the three interactive widgets).
  - `assets/` – generated images, MP4s and widget data (`trc_grid.json`, `snr_posterior.json`).
- `python/` – figure scripts (`fig_*.py`), shared palette `style.py`, `bns_import.py` (loads the paper's waveform code without editing it: aliases `ripple` to `ripplegw`, enables JAX float64), `hmc_data.py` (loads the HMC runs), `anim.py` (MP4 writer).
- `build.py` – regenerates everything: `python build.py` (or `python build.py hmc star` for a subset).
- `data/` – inputs copied from the paper's analysis: the HMC samples the figures read (`data/hmc`) and the waveform code (`data/paper_code`). See `data/README.md`.
- `audio/` – generated WAVs and spectrograms (not committed; see `.gitignore`). The soundtracks the story uses are already inside `site/assets/inspiral_chirp.mp4` and `bowl_resonance.mp4`; `python build.py sound` regenerates the rest.

## Preview
```
python -m http.server 8000 --directory site
```
then open http://localhost:8000. (Opening `index.html` directly will not load the widget data; browsers block `fetch` on `file://`.)

## Dependencies
numpy, scipy, matplotlib, pandas, pyyaml, jax, quadax, corner, pyvista, imageio, imageio-ffmpeg, and `ripplegw` from `git+https://github.com/tedwards2412/ripple.git`.

## Deployment
The story is published from this repo's `site/` folder by the workflow in `.github/workflows/pages.yml`.
- **One-time:** repo Settings, Pages, Build and deployment, Source: **GitHub Actions**.
- **Every update:** push to `main`. The workflow uploads `site/` and deploys it to
  https://astrojoebretz.github.io/cosmic-singing-bowls/ (the repo name sets the URL path, so keep it).
- The landing page at https://astrojoebretz.github.io/ links to the story; the story links back to it ("All stories") and to this repo ("Code and data"). The link-preview image is `site/assets/og-image.png`, made by `python/fig_og_image.py`.

## Honesty notes (also stated in captions)
- Chapters 1–4 visuals are labeled illustrations; the inspiral is slowed down and tidal stretching is exaggerated.
- The "Turn up the signal" widget rescales the real SNR-500 posterior about its best-fit value (width ∝ 1/SNR, bias fixed at +32); it is an approximation.
- The detectability chart is plotted from the paper's table (no raw mismatch data); the "retune the bowl" widget lets you combine effects, which the paper studies one at a time.
